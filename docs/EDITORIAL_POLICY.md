# 海选AI选题、来源与发布规则

版本2.0 · 2026-11-08

## 四个栏目

1. **今日情报**：默认每天3—5条，单独突出一条重磅。只有足够重要的内容才入选，不足3条明确说明；没有新一期保留旧期并注明日期。原文日期与精选日期分开，禁止把旧采访写成今日发布。
2. **一人公司**：国内案例为主，优先具体需求、客户、交付和可核查实践；不把“月入多少”的营销文章当作已验证收入。
3. **免费资源**：优先厂商官方文档。每条说明资格、地区、支付/认证、计费、有效期、核对日期、官方入口；网页规则已核对不等于亲自领取成功。
4. **工具雷达**：官方项目或原始仓库，描述解决的任务；不把历史增长量标成当月热度，价格、许可证与商用条件指向官方核实。

## 情报分类

固定为产品动态、行业动态、人物对话、报告解读，单层筛选。完整采访和报告进入历史分类，不强行要求每日覆盖所有类别。用户点击分类进入对应档案，默认首页仍只呈现本期少量精选。历史档案保留、每页10条。

官方发布和一手材料优先，其次为署名报道；国内搜索覆盖腾讯新闻、微博、36氪、人民网、新华网及地方记者采访。腾讯新闻保留原媒体/作者名称；微博优先认证媒体或本人，作为线索发现，访问受限交人工核对，不绕过登录。36氪当前 `/feed` 实测返回HTML，不作为可用RSS。

`data/domestic-sources.json` 维护域名白名单、公开索引、原文监测清单和来源用途。公开搜索结果可能稀少或偏离站点限制，必须再次检查域名，不能为凑数采纳不匹配的结果。来源健康需区分“搜索返回”“找到线索”和“公开正文可读”。一人公司候选保持待审核，不自动发布。

## 事实与证据

- 必须读取正文，不能仅凭标题扩写；没有可靠发布日期的候选不自动进入日报。
- 每个北京时间日最多生成5条，首页最多精选5条，同一主要来源最多2条；每天多次更新不能突破上限。候选同一事件合并，保留多来源链接。不同模型版本与独立事件不误合并。
- 解读明确为编辑建议，不捏造收入、客户量、时间和成本。营业收入、净利润、经常性收入分开；未经独立核验注明媒体报道/本人自述。
- 图片必须标为来源配图或本站编辑示意图；不能把示意图冒充现场。配图失败显示本地示意图，保持原文入口。不可公开使用的图使用原创示意图。
- 免费资源核对超过7天显示待核对，截止后显示过期。个人额度重置不包装为全平台统一事件。
- 不收录漏洞利用、批量注册、诱导充值或缺少来源的收益承诺。赞助和推广需明确标识。

## 审核与通知

爆料、纠错和领取反馈先入待审库。禁止公开密码、API Key、身份证明和支付信息。已审核反馈展示实际条数，不在样本稀少时编造领取成功率。

邮件需明确订阅同意与邮箱确认，退订可用。默认周精选；即时提醒需编辑为资源显式设置 `instantApproved: true`，并保证当日核对，通知进程去重。未开通SMTP不能声称已经订阅或发信。审核、候选与订阅数据不得打包公开。
