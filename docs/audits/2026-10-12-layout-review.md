# 2026-10-12 外观与布局优化

## 设计范围
首页新闻列表、详情页、AI 阅读助手和手机提问入口。保留深蓝、奶油白、薄荷绿品牌配色与新闻数据、筛选和模型接口。

## 八项设计自检
- 排版：降低普遍的重字重，建立标题、摘要、元数据层级，详情正文限制阅读行宽。
- 留白：外层最大宽度从 1240px 扩展至 1560px；减少普通卡片装饰与操作区高度。
- 视觉层级：取消第一条自动绿色强调，日期使用分隔线，新闻内容成为主体。
- 色彩：奶油白承载新闻、薄荷绿承载 AI；分类改为低饱和标签。
- 动效：卡片不再整体位移；保留短暂颜色与阴影反馈，减少动画偏好下停用旋转。
- 微交互：详情返回恢复列表滚动与筛选状态；聊天支持原生模态对话框、关闭与 Escape。
- 响应式：1100px 以下 AI 改为底部提问面板，桌面侧栏加宽并保持输入框可见；详情顶部对齐。
- 原创性：用日期节奏、新闻解读和上下文 AI 形成编辑阅读体验，与其他个人站点配色一致。

## 验证与限制
执行 lint、Python 单元测试、生产构建、体积预算和 Playwright 浏览器回归；覆盖 320、375、390、430、768、1024、1440px 首页与详情，额外检查 1920px 空间利用。实际查看 390px 手机面板与 1440px 桌面，正文和 AI 面板顶部误差 0px。

本地没有 PHP，三个接口单元测试本地跳过，由 GitHub Actions 的 PHP 环境执行。浏览器 AI 面板测试使用模拟成功响应，上线后另验证真实接口。奖项作为设计品质参考，不代表已获得奖项或官方评级。
