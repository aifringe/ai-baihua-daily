## 持续观察

- Core Web Vitals 的合格线需要真实用户 75 分位数据；当前以构建体积预算和 Playwright 回归防止明显退化，不能替代长期真实用户监控。
- 第三方原文可能临时返回 403 或 429。更新程序会排除订阅墙和不可读取正文，但来源站后续改变访问策略时仍需定期复核。
- 新闻事件去重属于启发式判断。已增加同事件和不同事件测试，仍需在每日更新后抽查误合并与漏合并。
