# 海选AI首版改建验收

日期：2026-11-08。范围：本地网站、内容、采集、互动API与部署准备。未操作生产服务器。

## 已实现

- 海选AI品牌、favicon与1200×630分享图；清爽绿色页面，四个一级栏目。
- 当前4条情报，重磅单列、逐条配图，保留各自原始日期；558条档案，四类筛选、搜索、排序、分页与本机收藏。
- 5个国内案例：温州腾讯SSV订单试点、杭州行业服务、独立产品维护、工业销售辅助、腾讯新闻南风窗经营走访。没有虚构收入。
- 3项官方资源：阿里云百炼、腾讯云国际站TokenHub、腾讯云DataBuddy。明确地区、资格、期限、计费；没有把国际站活动当作国内站通用资格。
- 11个工具入口。历史人物对话、报告并入情报；不再宣传未经本期核验的热度数字。
- 反馈、爆料入SQLite待审；订阅、偏好与退订的邮箱确认、单次令牌与限流；未配置SMTP返回503，不声称成功。
- 国内线索发现按域名限制，公开栏目＋搜索＋原文监测；微博线索不直接发布，正文不可访问保留待审。36氪RSS实测是HTML而停用；文章日期采用文章自身时间，避免把页面渲染时间当发布日。候选只保存短摘录、哈希和长度，不持久保存整篇转载正文。

## 验证结果

- lint通过，27项Python测试通过，12项端到端测试通过。
- 响应式：320、375、390、430、768、1024、1440px。四栏、详情图片均能显示，无横向溢出。390和1440实看并保存截图。
- 走通：档案搜索、四类筛选、分页排序、收藏刷新保留、原文链接属性、案例详情、资源条件和本机领取标记、弹窗关闭恢复焦点、断网降级、坏ID与空结果、反馈审核隔离、跨站拒绝、非法输入、SMTP未配置状态。
- 构建预算：gzip JS约80.5KiB，CSS约8.6KiB，均通过现有上限。国内头图优化为约189KiB。本地检查不代表生产75分位Core Web Vitals。
- 主要外链实测：多数返回200；人民网浙江案例当前连接不稳定，页面证据栏已注明；WEF旧报告页返回403，档案详情已注明访问受限；MCP官网返回308，未声称200。
- 数据库不在dist；没有更改personal-site或迁移原Git仓库；未添加密钥与真实SMTP凭据。

## 尚未验证或启用

- 生产部署与GitHub Actions运行；本次没有推送main。
- Python服务、nginx代理、SQLite备份与邮件定时器的生产安装。
- 真实SMTP发送、邮箱DNS、收件箱送达率及生产退订闭环。自动测试只模拟发信，未给真人发送邮件。
- 国内各来源未来的稳定可读性；检索返回不等于每次都有新案例。当前候选仍需编辑核验，不承诺自动产出赚钱结论。
- 公开注册账号、完整社区、收入验证榜不在此首版；提醒通过邮箱确认，不伪造会员系统。
